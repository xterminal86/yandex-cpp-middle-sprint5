План реализации проекта библиотеки для работы с геометрическими примитивами
Подготовьтесь к работе:
Откройте шаблон проекта.
Выполните инструкции в разделе «Начало работы».
Соберите проект и запустите приложение по шагам в разделе «Сборка проекта и
запуск тестов».
Изучите файл geometry.hpp в котором реализованы методы для удобной работы с
геометрическими примитивами.
Убедитесь, что все методы, реализованные в классах файла geometry.hpp (включая
Point2D и Lines2DDyn), содержат все возможные спецификаторы и атрибуты, которые
можно к ним применить в конкретном случае.
В файле geometry.hpp реализуйте std::formatter<std::vector<geometry::Point2D>>,
который может принимать:
Пустой список форматирования {} — в этом случае он выводит список точек в одну
линию.
{:new_line} — в этом случае он должен выводить каждую точку на новой линии с
отступом \t.
 Используйте std::string_view, std::string_view::starts_with и метод parse,
 который при использовании форматирования new_line должен возвращать текущее
 значение итератора контекста и длину строки спецификатора форматирования.
В файле intersections.hpp реализуйте класс IntersectionVisitor для поиска
пересечений между фигурами. Операции поиска пересечений должны быть реализованы
только для следующих комбинаций типов фигур: Line & Line, Line & Circle,
Circle & Circle. Для всех остальных комбинаций типов реализовывать пересечение
не нужно. При попытке вызова операции пересечения для неподдерживаемой
комбинации типов нужно выбросить исключение std::logic_error.

В файле queries.hpp изучите:

Класс PointToShapeDistanceVisitor, реализующий паттерн «посетитель» для поиска
расстояния от точки до фигуры.
Класс ShapeToShapeDistanceVisitor, реализующий паттерн «посетитель» для поиска
расстояния между двумя фигурами.
В файле queries.hpp реализуйте функции-помощники для применения
классов-посетителей DistanceToPoint, GetBoundBox, GetHeight,
BoundingBoxesOverlap и DistanceBetweenShapes.

В файле shape_utils.cpp реализуйте:

Функцию FindAllCollisions для поиска всех пересечений между фигурами методом
Bounding Box.
Функцию FindHighestShape для поиска самой высокой фигуры.
При помощи монад в файле shape_utils.cpp реализуйте функции MakeCircle, MakeLine,
MakeTriangle, MakeRectangle и MakePolygon
Обратите внимние на возвращаемое значение в файле shape_utils.cpp в функции
ParseSingleShape.
В пространстве имён namespace geometry::convex_hull аннотируйте функцию
std::vector<Point2D> GrahamScan(std::span<Point2D> points) как noexcept и
измените её содержимое, чтобы она не выбрасывала исключение. Для этого
воспользуйтесь типом std::expected.
В пространстве имен namespace geometry::triangulation аннотируйте функцию
inline std::vector<DelaunayTriangle>
DelaunayTriangulation(std::span<const Point2D> points) как noexcept и измените
её содержимое, чтобы она не выбрасывала исключение. Для этого воспользуйтесь
типом std::expected.
Реализуйте функции, описанные в файле main.cpp, следуя комментариям в коде и
используя созданные ранее классы и функции-помощники: PrintAllIntersections,
PrintDistancesFromPointToShapes, PerformShapeAnalysis, PerformExtraShapeAnalysis.

Завершите работу:

Протестируйте разработанные функции и классы на корректность с помощью тестов во
фреймворке GTest.
Убедитесь, что код соответствует современным стандартам C++.
Проверьте отсутствие утечек памяти и корректное управление ресурсами.
Убедитесь, что используются современные возможности C++23, включая новые
словарные типы, алгоритмы STL, диапазоны.
